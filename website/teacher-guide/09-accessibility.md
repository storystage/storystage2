# 9. Accessibility

StoryStage is built to the Web Content Accessibility Guidelines (WCAG) 2.2 at level AA, so that every learner in the class can take part.

| Need | What StoryStage does |
|---|---|
| **Keyboard only** | Everything in all three tabs can be done from the keyboard. Every drag has a keyboard alternative: select it, choose **Move to…**, and use the arrow keys. Focus is always clearly shown. Keyboard shortcuts are listed in **Learn**. |
| **Larger text** | **Settings › Accessibility › Text size**: 100%, 125% or 150%, without shrinking the working area. Settings, Learn and dialogs also reflow when the browser is zoomed. |
| **Reading** | Tips and guided steps can be **read aloud**. Words are short and plain, and every main control has an icon as well as a label. |
| **Writing** | A **microphone** button beside every text box turns speech into text, on the device, in the apps (not in the browser version). The one exception is the Claude key, which is never spoken. |
| **Hearing** | All speech has **captions**, always, in the app and in exported films. |
| **Sight** | Text contrast meets WCAG AA in both themes; status is never shown by colour alone; screen readers get a name and role for every control, and changes the learner didn't make (such as export progress) are announced. |
| **Touch and motor** | Every target is at least 44 × 44 pixels. |
| **Light or dark** | **Settings**: Dark (the default), Light, or Match this device. |
| **Two code editors** | Some learners find Blocks easier; others find Tiles' structure clearer. Teachers can set the default per class. |

## Devices

StoryStage needs a window at least 1024 pixels wide (an iPad held sideways, a laptop or a Chromebook). In a narrower window, it asks to turn the iPad or widen the window, rather than squashing the work.
