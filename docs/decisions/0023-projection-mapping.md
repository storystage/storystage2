# 0023 Projection mapping

- **Status:** settled
- **Decided:** 18 Oct 2026
- **Source:** workplan section 2 (fixed decisions)

## Decision

A Projection stage (surfaces, virtual projectors, preview), classroom projection from the desktop app, and Export for projection, including an Export to Pixera package (WP23). Pixera's project file format isn't published, so the export is a package plus a build script for Pixera's API, not a Pixera project file.
