# 0040 Welsh first, in release 1.1

- **Status:** settled; builds on [0036](0036-languages.md), which it doesn't replace
- **Decided:** 25 Oct 2026, by the owner
- **Source:** the owner's answer in session D, on the curriculum mapping (`docs/curriculum/mapping.md` section 8, #68)

## Decision

The first release and the pilot stay in **English (UK) only** (0036). **Welsh is the first language added, in release 1.1.** Scottish Gaelic and Irish follow later, if schools ask for them.

## Why

Welsh is compulsory in the Curriculum for Wales, many learners are taught through Welsh, and Wales is StoryStage's closest curriculum fit (`docs/curriculum/wales.md`). Because 0036 already puts every string in translation files, Welsh is a translation, not a rebuild. Release 1.1 planning (workplan section 6b) includes the translation and its review by Welsh-speaking teachers.
