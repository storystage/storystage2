# 0033 Narrow windows

- **Status:** settled
- **Decided:** 25 Oct 2026, by the owner
- **Source:** the owner's answer in the S5 session, on the Direction A handoff (#58)

## Decision

The studio is designed for windows **1024 px wide and up** (laptop, Chromebook and iPad landscape; `docs/spec/07-ux.md` §1). Below 1024 px, for example an iPad in portrait or a narrow desktop window, it shows a calm full-screen note asking the learner to turn the iPad sideways or make the window wider. There is no portrait layout in the first release.

The note is a neutral note, not an error, and the learner's work is kept: widening the window brings the studio straight back.
