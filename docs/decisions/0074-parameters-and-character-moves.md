# 0074 Parameters, and a character's own procedures and functions

- **Status:** settled
- **Decided:** 21 Nov 2026, by the owner
- **Source:** the owner's answers in the S8 session, on S8's comparison of StoryStage 2 with Alice 3; confirmed in the S1 session the same day

## Decision

1. **Parameters, this version.** A learner's procedures and functions can take parameters, as Alice 3's do, in both code editors.
2. **A character's own moves, this version.** Procedures and functions can belong to a character's class, so every scene can use them: write "penguin waddles" once and call it in any scene.
3. **Next version:** class properties (a class's own values) and `.a3c` export of a class.
4. **Not added:** Alice's `isLetter` and `isDigit` functions and its shapes' radius properties stay out of the Story API. No change.

## Who does what

- **S5 and S6** split the editor work between the two code editors (Blocks and Tiles), as they have agreed.
- **S2** checks that the runtime calls a class's procedures and functions with their arguments (workplan 6.1 already covers parameters on a scene's methods).
