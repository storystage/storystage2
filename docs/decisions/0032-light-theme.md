# 0032 Light theme

- **Status:** settled
- **Decided:** 25 Oct 2026, by the owner
- **Source:** the owner's answer in the S5 session, on the Direction A handoff (#58)

## Decision

The first release has a **light theme as well as the dark one** (WP12.2). Direction A draws only the dark theme, so the light theme is **drawn as mock-ups and approved by the owner before any light-theme code is built**. S5 draws it as part of 12.1, from the same role-named tokens.

Until the light mock-ups are approved, WP12b builds the dark theme only, with every colour taken from a role token (`panel-2`, `chalk`), so the light theme later swaps values and nothing else.
