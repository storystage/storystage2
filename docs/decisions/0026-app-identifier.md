# 0026 App identifier

- **Status:** settled
- **Decided:** 21 Oct 2026, by the owner (#20)
- **Source:** the owner's answers in the S1 session

## Decision

The apps keep the identifier `org.storystage.storystage2` (bundle id on iPad and macOS, application id on Android). It can't change after the first store release. It assumes StoryStage controls the `storystage.org` domain; if not, change it before WP15.4–15.6, the first signed store builds.
