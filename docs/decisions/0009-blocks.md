## Decision

Two code editors in the first release, over the same program: **option B**, Blockly (Apache-2.0) customised to look and behave like Alice's tiles; **option C**, an Alice-style tile editor rebuilt in React. Learners can switch at any time; the teacher sets each class's default. A pilot study (WP19.5–19.8) decides which one continues. Both have a read-only text view.
