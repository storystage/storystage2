# Security

StoryStage 2 is used by children in schools and clubs. Please report security problems privately, not in a public issue.

**How to report:** use GitHub's private vulnerability reporting: the **Security** tab of this repository, then **Report a vulnerability**.

Especially welcome: any way for web code to read or use the Claude API key; any way around the native layer's policy checks; anything that sends learner data, audio or pictures off the device; and unsafe handling of imported `.storystage`, `.a3p`, glTF or Fountain files.

Please don't include real API keys or anyone's personal data in a report.
